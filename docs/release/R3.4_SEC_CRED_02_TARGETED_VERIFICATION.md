## 3. Cross-User Password-Change Protection

### Test: `crossUser_cannotChangeOtherUsersPassword`

**Scenario:**
- User A (`testuser`) attempts to change User B's (`normaluser`) password
- Request includes `{"username":"normaluser","oldPassword":"...","newPassword":"..."}`
- User A's JWT is used for authentication

**Verification:**
```java
// Capture User B's original password hash
String originalPasswordHash = userWithoutRequirement.getPassword();

// User A attempts to change User B's password
mockMvc.perform(post("/api/v1/auth/change-password")
    .header("Authorization", "Bearer " + tokenForUserRequiringChange)
    .content("{\"username\":\"normaluser\",...}"));

// Verify User B's password was NOT changed
assertThat(userWithoutRequirement.getPassword())
    .isEqualTo(originalPasswordHash);
```

**Security Guarantee:**
- `AuthController.changePassword():115` uses `TenantContext.username()` from JWT, not request body
- Even if attacker provides target username in request, controller ignores it
- User B's password remains unchanged after rejected attempt
